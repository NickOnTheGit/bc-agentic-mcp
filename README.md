# API Drift Detector - POC

Proof-of-concept for detecting API drift between API versions (work in progress).

## Overview

This repository contains an early POC for tooling to detect changes in API surface (endpoints, schemas, etc.) between versions, to help surface unintentional breaking changes.

## Quick start

- Clone the repo
- Inspect source and tests to understand current checks

## Goals

- Compare API specifications (OpenAPI / Swagger) across versions
- Highlight breaking changes and suspicious differences
- Provide actionable report output
